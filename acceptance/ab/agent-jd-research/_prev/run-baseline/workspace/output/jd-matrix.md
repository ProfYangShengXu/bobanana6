## 核心技术栈汇总（高频出现）

| 技术方向 | 关键词 |
|----------|----------|
| **框架** | LangChain、LangGraph、CrewAI、AutoGen |
| **RAG** | 分块、嵌入、向量索引、检索、重排序、混合检索 |
| **Agent** | 工具调用、Function Calling、多 Agent 协作、记忆机制 |
| **部署** | Docker、K8s、模型量化、vLLM、加速推理 |
| **向量库** | Milvus、Qdrant、Chroma、Faiss |
| **微调** | LoRA、P-Tuning、QLoRA、SFT、微调评估 |
| **评估** | Rouge-B、BLEU、Ragas 评估、自定义指标 |
| **其他** | PyTorch、HuggingFace、Prompt Engineering、LLM 原理 |
