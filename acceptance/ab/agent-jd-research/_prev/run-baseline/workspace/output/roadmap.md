## 一、学习阶段划分

### 阶段：阶段一：基础夯实（2-4 周）

> **建立扎实的大模型理论基础**

**核心知识点**：
- Transformer 架构（自注意力机制、残差连接、Feed Forward）
- LLM 训练流程（Pre-training、SFT、RLHF）
- HuggingFace 工具链（Model Hub、Datasets）
### 阶段一关键点（2-4 周）
- 阅读《Attention Is All You Need》论文
- 用 PyTorch 实现一个 tiny GPT
- 跑通 HuggingFace Text Classification 示例

### 阶段：阶段二：Framework 与 RAG（4-6 周）

> **掌握主流框架与 RAG 技术**

**核心知识点**：
- LangChain / LangGraph 基础用法
- RAG 完整链路（分块、嵌入、索引、检索、重排序）
- 向量数据库（Milvus、Qdrant、Chroma）
### 阶段二关键点（4-6 周）
- 搭建完整的 RAG 系统
- 对比 LangChain vs LangGraph

### 阶段：阶段三：Agent 核心（4-6 周）

> **掌握 Agent 架构设计与工具调用**

**核心知识点**：
- Function Calling 原理与实战
- 工具链设计（注册、解析、调用）
- Agent 协同模式（主从、并行、分层）
- 记忆机制（短期/长期记忆、持久化）
### 阶段三关键点（4-6 周）
- 用 LangGraph 实现多 Agent 协作
- 设计自己的工具函数
- 理解 Prompt 工程最佳实践

### 阶段：阶段四：进阶优化（4 周）

> **掌握微调与推理优化**

**核心知识点**：
- LoRA / P-Tuning / QLoRA 微调
- 推理优化（量化、蒸馏、缓存）
- 模型对齐（DPO、GRPO）
- 评测体系（ Rouge-B，BLEU，自定义指标）
### 阶段四关键点（4 周）
- 微调一个领域模型
- 设计评估 Harness

## 常见陷阱

1. **只会名词不会写代码**：Agent 是工程问题，会写才是核心
2. **项目泛泛不能讲清楚**：能讲清记忆机制、工具调用、上下文管理才能过面试
3. **忽视工程落地**：RAG 召回率 100% 但延迟 10 秒也是失败
4. **不看源码**：不读开源框架源码，无法理解核心设计
5. **框架依赖过强**：只用 LangChain 不放 LangGraph，架构能力不足

## 持续学习

1. **动手 > 看书**：代码实现 > 理论学习的比例应该 6:4
2. **项目驱动**：所有学习最终要落地到项目
3. **持续更新**：关注最新论文和技术，每周至少读 2-3 篇
4. **面试是双向选择**：不要害怕被拒，每次面试都是学习机会
5. **技术深度 > 广度**：在核心方向（如 RAG 或 Agent）做到深入
6. **保持健康**：学习是持久战，注意休息和运动
