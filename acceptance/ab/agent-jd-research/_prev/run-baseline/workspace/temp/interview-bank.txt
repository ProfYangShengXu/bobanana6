# 📚 AI Agent 面试题库（2026 版）

按主题分类整理的真实面试题目，每道题:**题干** + 一句话**考察点**。

---

## Agent 架构与多 Agent 协作（A2A / 主从 / workflow）

1. **LangGraph 如何处理循环支持（cycle）？与 DAG 有什么区别？** （考察点：考察对 Graph 模式的理解，尤其是循环边和人工介入点的设计）

2. **ReAct Agent 和 Supervisor Multi-Agent 的核心区别是什么？** （考察点：ReAct 是单 Agent 内部思考 - 行动循环，Supervisor 是多 Agent 协作模式）

3. **A2A（Agent-to-Agent）协议如何解决多 Agent 通信问题？** （考察点：考察 Agent 间通信协议（如 XML/JSON Schema）与协调机制）

4. **多 Agent 系统中如何避免 Agent 间信息丢失？状态持久化怎么做？** （考察点：检查点机制、共享状态管理、中断恢复）

5. **MCP 解决的是工具对接的标准化问题。没有 MCP 的时候，每接一个新工具就要写一套对接代码。** （考察点：MCP 是工具层的标准化，Skill 是能力层的复用）

6. **Skill 是在 MCP 之上的进一步抽象，解决的是能力复用问题。Skill 把 Agent 的某个能力封装成一个"技能包"。** （考察点：Skill 定义能做什么、需要什么输入、输出什么格式、依赖哪些工具）

## 上下文工程与记忆（长会话、压缩、长期记忆、上下文污染）

7. **长对话中如何管理上下文？Token 截断和压缩策略有哪些？** （考察点：滑动窗口、摘要压缩、向量记忆）

8. **如何设计 Agent 的长期记忆机制？短期记忆 vs 长期记忆的存储策略？** （考察点：短期=会话上下文，长期=向量知识库/向量索引）

9. **上下文污染（context pollution）是什么？如何检测和治理？** （考察点：无关知识混入导致的幻觉，需要重排序/过滤）

## RAG（检索、改写、混合检索、RRF、rerank、评测）

10. **混合检索（hybrid retrieval）如何实现？BM25 + Dense 的权重怎么调？** （考察点：检索策略组合、权重学习）

11. **RAG 系统中如何实现重排序（rerank）？Re-ranking 提升效果的关键指标是什么？** （考察点：rerank 模型选择（BGE-Reranker）、重排阈值）

12. **RRF（Reciprocal Rank Fusion）如何整合多个查询结果？公式是什么？** （考察点：公式：rank(a) = 1/(k^2 + k_1·rank(a))）

13. **GraphRAG 相比传统 RAG 的优势是什么？图谱在什么场景最有价值？** （考察点：知识图谱结构信息、社区检测）

14. **RAG 系统如何支持多轮对话？指代消解怎么做？** （考察点：对话历史管理、实体对齐）

15. **如何解决 RAG 的幻觉问题？技术路线有哪些？** （考察点：引用标注、自我反思、重排序、人工审核）

---

## 模型层（微调/SFT、推理优化、幻觉治理、评估）

16. **LoRA 和 QLoRA 的区别？QLoRA 如何节省显存？** （考察点：LoRA=低秩适配，QLoRA=4-bit 量化 + LoRA）

17. **SFT（监督微调）和 RAG 的使用场景区别是什么？** （考察点：微调学能力，RAG 补充知识）

18. **在什么场景下必须使用微调？RAG 什么时候不够用？** （考察点：格式输出、稳定推理链路、领域知识深度）

19. **DeepSeek R1 的推理能力和强化学习方法是什么？** （考察点：R1 的 Chain-of-Thought 推理、RL fine-tuning）
