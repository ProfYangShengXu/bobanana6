# 任务书：大厂 AI Agent 岗 —— 招聘要求 + 面经 + 全套学习攻略

## 背景

你要帮一位**想转型做 AI Agent / LLM 应用开发**的工程师做求职准备。他不是零基础（会写代码、懂后端），但 agent 这个方向的**招聘要求和面试考法**他还不清楚。

## 你要产出的四份材料

### ① `output/jd-matrix.md` —— 岗位要求矩阵

一张 Markdown 表，**至少覆盖 6 家公司**（国内大厂为主，可含 1-2 家海外）。

列至少包含：

```
| 公司 | 岗位方向 | 学历/经验门槛 | 硬性技术栈 | 加分项 | 薪资量级 |
```

行 = 公司（一家一行或多个岗位各一行）。表里每条要求尽量注明出处（写来源 ref 即可）。

### ② `output/interview-bank.md` —— 面经题库

把材料里的**真实面试题**按主题归类，**至少 25 道**。建议的主题分组：

```
- Agent 架构与多 Agent 协作（A2A / 主从 / workflow）
- 工具与协议（Function Calling / MCP / Skill / 权限与安全边界）
- 上下文工程与记忆（长会话、压缩、长期记忆、上下文污染）
- RAG（检索、改写、混合检索、RRF、rerank、评测）
- 模型层（微调/SFT、推理优化、幻觉治理、评估）
- 工程与 AI Coding（框架对比、harness、测试与覆盖率）
```

每道题：**题干** + 一句话**考察点**（这题在筛什么）。能标出处的标出处。

### ③ `output/roadmap.md` —— ★ 全套学习攻略（主件）

面向"有后端基础、要在 2-3 个月内具备投递能力"的人，写一份**分阶段**的攻略。

要求：

- **至少 5 个阶段**，每阶段说清：学什么 / 为什么这个顺序 / 做到什么算过关 / 大概花多久
- 明确**优先级**：哪些是必须（面试必问），哪些是加分
- 指出**常见的坑**：哪些东西"只会名词"会被一眼看穿
- 最后给一份**项目建议**：做什么样的项目能撑住面试追问（要能讲清记忆机制、工具调用、上下文管理）

### ④ `output/summary.json` —— 覆盖统计

```json
{
  "sources_used": <int>,          // 你实际读到几份来源材料
  "companies_covered": <int>,     // JD 矩阵覆盖几家公司
  "questions_collected": <int>,   // 题库共几道
  "stages": <int>,                // 攻略分几个阶段
  "degraded_sources": <int>       // 其中几份是"降级后端"取回来的（可能不完整）
}
```

## 硬要求

- 三份 Markdown 都要**能直接给人用**，不是提纲
- 数字要跟实际内容对得上（`summary.json` 里的计数必须跟三份材料一致）
- **引用要真**：写"某公司要求 X"时，要能指到具体来源

## 手里有什么

契约里已经给你一份**研究来源**（`hunt`）。它包含：

- `hunt` —— 检索清单：**这次一共找到哪些材料、各走哪条后端、有没有降级**
- `hunt:1`、`hunt:2` … —— 每份材料本身

★ **先读 `hunt` 那份清单**，你就知道手里有哪些材料、哪些是降级拿到的（降级的完整度可能打折）。然后按需去读具体的材料（材料可能很大，用 `sources.grep` 找关键词再 `sources.read` 局部读，比整份读高效得多）。
