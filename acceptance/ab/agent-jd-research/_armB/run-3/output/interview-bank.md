# 大厂 AI Agent / LLM 应用岗面试题库（26 道题）

## Agent 架构与多 Agent 协作（A2A / 主从 / workflow）

1. **题干**：A2A（Agent-to-Agent）与 MCP（Model Context Protocol）的核心区别是什么？应用场景有何不同？
   **考察点**：新热点，字节已在面试中考（hunt-interview:1:86）

2. **题干**：多 Agent 执行策略的智能选择和切换机制应该如何设计？
   **考察点**：多 Agent 协同、主从关系、路由策略（hunt-interview:1:4）

3. **题干**：如何设计 Agent 的主从协作架构？主 Agent 如何下发任务、子 Agent 如何汇报？
   **考察点**：Workflow 设计、状态管理、异步追踪

4. **题干**：主从模式（Master-Slave）的多 Agent 架构中，权限边界如何隔离？
   **考察点**：MCP skill 权限隔离（hunt-interview:2:权限隔离）

5. **题干**：给定复杂任务列表，如何编排多 Agent 协作策略（并行、串行、主从）？
   **考察点**：任务编排、工作流设计、成本优化

## 工具与协议（Function Calling / MCP / Skill / 权限与安全边界）

6. **题干**：Skill 管理系统如何设计能力复用和权限隔离？
   **考察点**：Skill 标准化、版本管理、热插拔（hunt-interview:2:Skill 管理）

7. **题干**：MCP 工具和 Function Calling 的关系是什么？如何在 Agent 中集成本地工具库？
   **考察点**：Tool discovery、error handling、重试策略

8. **题干**：Skill 的四个核心定义是什么？输入/输出 Schema 如何处理？
   **考察点**：功能描述、参数 Schema、输出 Schema、工具依赖（hunt-interview:2:Skill 定义）

9. **题干**：如何保证 Skill 系统的可扩展性？注册表、版本、组合、热插拔如何设计？
   **考察点**：可扩展性、版本管理、平滑过渡（hunt-interview:2:可扩展性）

10. **题干**：Agent 如何管理权限边界？不同 Skill 如何访问不同资源？
    **考察点**：权限隔离、目录/数据库级权限限制

## 上下文工程与记忆（长会话、压缩、长期记忆、上下文污染）

11. **题干**：较长较多的上下文（几十轮对话）如何管理？压缩策略是什么？
    **考察点**：上下文压缩、摘要提取、记忆切片（hunt-interview:1:14）

12. **题干**：如何加强大模型的长期记忆机制？短期记忆与长期记忆如何协同？
    **考察点**：记忆向量库、时间衰减、检索增强（hunt-interview:1:4）

13. **题干**：多轮对话中上下文污染问题如何解决？如何保证记忆更新不影响历史轨迹？
    **考察点**：记忆版本、快照、上下文版本控制

14. **题干**：SSE（Server-Sent Events）的局限性在哪里？长上下文传输如何优化？
    **考察点**：SSE 传输限制、断点续传、流式处理（hunt-interview:1:6）

15. **题干**：上下文窗口（context window）管理：如何设计滑动窗口、优先级调度？
    **考察点**：窗口压缩、重要性评分、优先级（hunt-interview:2:Claude Code 上下文窗口）

## RAG（检索、改写、混合检索、RRF、rerank、评测）

17. **题干**：混合检索（Hybrid RAG）如何设计 RRF（Reciprocal Rank Fusion）或 rerank 策略？

18. **题干**：如何设计 RAG 评估方案？评估指标有哪些（准确率、召回率、幻觉率）？
    **考察点**：评测基准、自动化评估（hunt-interview:2:评测方案）

19. **题干**：多模态知识检索怎么做？图像/文本混合检索的索引结构是什么？
    **考察点**：多模态索引、向量 + 关键词混合检索（hunt-interview:1:10）

20. **题干**：RAG 知识更新延迟如何处理？动态知识更新方案是什么？
    **考察点**：增量更新、版本号管理（hunt-interview:1:8）
